# 暂停评论分类与关键词高亮：设计说明

日期：2026-09-09

## 目标

暂时停用评论分类和关键词高亮相关的可见界面与交互，但保留现有组件、函数、样式和数据字段，以便后续低成本恢复。

## 已确认范围

### 暂停评论分类

- 隐藏 Statement、Question、Exclamation、Suggestion、Sarcasm 分类筛选按钮。
- 隐藏基于 `comment_type` 的分类饼图及图例。
- 隐藏嵌入式评论中的分类标签。
- 评论卡片不再显示分类色边框。
- Tooltip 不再显示 `Type` 信息。
- 句子评论不再按 `comment_type` 过滤。

### 暂停关键词高亮

- 隐藏 `Frequent Words` 控件。
- 隐藏高频词图例。
- 正文句子不再圈选或突出显示高频词。
- 全局评论、段落评论和句子评论不再加粗、着色或加背景突出 `matched_keywords`。

## 保留功能

- 评论正文、用户信息、点赞数和回复数正常展示。
- 点赞数与回复数筛选保持不变。
- 句子评论、段落评论和全文评论保持不变。
- Sentence-End、Between-Line、Click-to-Show 三种布局保持不变。
- 与评论数量相关的标记和交互保持不变。

## 实现方案

在前端代码内增加集中式内部功能配置，例如：

```js
const featureFlags = Object.freeze({
  commentClassification: false,
  keywordHighlight: false
});
```

该配置仅存在于代码中，不渲染为界面控件。

模板使用功能配置控制分类图例、标签、饼图和高频词相关控件是否渲染；渲染函数与筛选函数根据配置选择当前的普通展示路径或原有增强路径。原有实现代码不删除。

后续恢复时，将相应配置值改为 `true`，无需重新编写原有分类和高亮逻辑。

## 数据与后端

本次不修改 JSON 数据结构和 Tornado 接口。`comment_type`、`matched_keywords` 和 `high_freq_words` 字段可以继续返回，只是在功能关闭时不用于可见展示或过滤。这可减少变更范围，并保证恢复能力。

## 验收标准

1. 页面中看不到任何分类筛选按钮、分类饼图、分类标签或分类色边框。
2. 页面 Tooltip 中不出现评论 Type 信息。
3. 关闭分类功能后，任何分类的评论均不会因为类型而被过滤。
4. 页面中看不到 `Frequent Words` 控件或高频词图例。
5. 正文和评论内容均以普通文本展示，不出现关键词圈选、加粗、着色或背景高亮。
6. 点赞/回复筛选、评论展示和三种布局仍可正常使用。
7. 内部功能配置不会显示在界面上。
8. 原有分类与高亮实现代码仍保留，可通过内部配置恢复。
